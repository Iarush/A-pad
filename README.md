# A-pad
A  custom Macropad with a special A-shaped keypad

## Specs
8 Mx Cherry Keys
EC11 Rotary Encoder
0.91" OLED Display
Seeed XIAO RP2040 Microcontroller
Custom-made PCB
Custom-made case and plates


## CAD Model

The Case is constructed using the sandwhich plating method. 3 plates were made. A bottom plate where screws are added, a middle frame amidst which the PCB rests, and finally a top switchplate for an aestheic look tht hides the screws.
![CAD Model](images\CAD.png)

### Unique Features

- Switchplate is deeply bezeled aroung the OLED to allow easier viewability
- An "island" is created at the center of the A which is compeletely seperate from other parts of the switchplate but is secured with an M3 screw.
- Rotary Encoder top is also a CAD Model
CAD was made in Onshape
